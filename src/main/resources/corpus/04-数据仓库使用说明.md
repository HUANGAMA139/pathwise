# 数据仓库使用说明

## 一、数据刷新频率

销售数据**每日凌晨 3 点全量刷新**。

- 当日新增订单，最迟于**次日凌晨**可见。
- 刷新期间（约 3:00–3:20）查询可能返回不完整数据，请避开该时段。

## 二、核心表说明

### 订单表 `sales_orders`

主要字段：

| 字段名 | 类型 | 含义 |
|---|---|---|
| `order_id` | varchar | 订单号，格式 `ORD-` + 8 位数字 |
| `region` | varchar | 销售区域，取值见《销售区域划分规则》 |
| `order_amount` | decimal | 订单金额，不含税 |
| `refund_amount` | decimal | 退货金额，不含税 |
| `status` | varchar | 订单状态，取值见《销售数据统计口径说明》 |
| `completed_at` | timestamp | 订单完成时间，**统计归属期间以此为准** |
| `created_at` | timestamp | 订单创建时间 |
| `product_code` | varchar | 产品编码，取值见《产品线与编码规则》 |

### 产品表 `products`

| 字段名 | 类型 | 含义 |
|---|---|---|
| `product_code` | varchar | 产品编码 |
| `product_name` | varchar | 产品名称 |
| `line_code` | varchar | 所属产品线编码 |

## 三、查询注意事项

1. **统计销售额时用 `completed_at` 而不是 `created_at`。** 这是最容易写错的字段，
   原因见《销售数据统计口径说明》第二节。
2. **`refund_amount` 可能为 NULL。** 计算净销售额时用 `IFNULL(refund_amount, 0)`。
3. **区域字段存的是区域名，不是省份名。**

## 四、常见误解

**误解一：数据是实时的。**
不是，是 T+1。当日下单的数据看不到。

**误解二：表名是 `orders`。**
是 `sales_orders`。业务库里另有一张 `orders_archive` 是历史归档表，不要用它做当期统计。
