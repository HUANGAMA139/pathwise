# 销售数据统计口径说明 v3.2

本文件规定销售相关指标的统计口径。所有对外输出的销售数据必须遵循本口径。

## 一、销售额的定义

**销售额 = 订单金额 − 退货金额**

其中：

- **订单金额**（对应订单表的 `order_amount` 字段）指订单创建时的成交金额。
- **退货金额**（对应 `refund_amount` 字段）指该订单已实际退回的金额。

**两者均不含增值税。** 如需含税口径，请另行说明，默认对外口径为不含税。

## 二、归属期间的判定

销售额**按订单完成时间**归入所属期间（季度／月度），**不按创建时间**。

- 未完成订单（状态不为 `COMPLETED`）**不计入**任何期间的销售额。
- 跨期完成的订单，归入实际完成那一期。

> 这一条是历史踩坑点：2024 年及以前按创建时间统计，导致「已下单未完成」的金额被提前计入，
> 造成季度数据虚高。2025 年起统一改为按完成时间。

## 三、订单状态的含义

| 状态值 | 含义 | 是否计入销售额 |
|---|---|---|
| `CREATED` | 已创建，未支付 | 否 |
| `PAID` | 已支付，未完成 | 否 |
| `COMPLETED` | 已完成 | **是** |
| `REFUNDED` | 已全额退款 | **是**（订单金额与退货金额相等，净额为 0） |
| `CANCELLED` | 已取消 | 否 |

## 四、常见误解

**误解一：销售额就是收到的钱。**
不是。销售额是**净额口径**，已经扣除了退货。收到的钱还要考虑账期，和销售额不是一回事。

**误解二：订单金额就是销售额。**
只有状态为 `COMPLETED` 或 `REFUNDED` 的订单，其订单金额才进入计算。

**误解三：退货金额只在实际退款到账后扣减。**
不是。退货金额在**审核通过时**即扣减，不等资金实际到账。
